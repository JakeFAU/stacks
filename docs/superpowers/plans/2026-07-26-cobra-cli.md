# Cobra CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Stacks' handwritten CLI parsing with a fresh, lazy Cobra command tree while preserving typed configuration validation, provider isolation, private-output boundaries, and existing operational behavior.

**Architecture:** `internal/cli` constructs a new Cobra root for each execution and emits a typed `Invocation` only from validated leaf commands. `internal/app` validates the invocation's application command before lazily resolving the selected existing command from `cmd/stacks`; the selected command receives typed arguments and never reparses user input. Cobra remains a root-module transport dependency and does not enter `core`, `adapters/postgres`, provider, storage, or domain contracts.

**Tech Stack:** Go 1.26, `github.com/spf13/cobra v1.10.2`, Go standard `testing`, existing Zap/OpenTelemetry/application composition.

## Global Constraints

- Implement only Cobra CLI transport; do not add Viper, configuration files, remote configuration, or configuration precedence behavior.
- Add exactly `github.com/spf13/cobra v1.10.2` to the root module; do not add it to `core` or `adapters/postgres`.
- Do not use `cobra-cli`, global mutable Cobra commands, generated command scaffolding, plugins, reflection, or a remote command registry.
- Construct a fresh Cobra root for every execution and test.
- Preserve no-argument server startup and explicit `stacks serve`; both reject positional arguments.
- Preserve `Settings.Validate(command)` as the authoritative command-specific validation and run it before constructing PostgreSQL, Google, AWS, directory, or model boundaries.
- Help, completion, unknown commands, invalid positional arguments, and invalid flags must not construct application providers.
- Configure Cobra with `SilenceErrors: true` and `SilenceUsage: true`; `main` remains the sole final error reporter.
- Keep private entity, review, transcript, and analysis content confined to explicit stdout; syntax errors must not echo private argument values.
- Support only documented double-dash long flags `--name`, `--email`, and `--entity`; single-dash long forms are not a compatibility contract.
- Reject blank `review create --name`; distinguish omitted `review accept-directory --entity` from an explicitly blank value, rejecting the latter.
- Preserve the exact `delete-local-stacks-postgres` database-reset confirmation and all existing resetter guards.
- Return underlying cancellation, provider, storage, and domain errors without replacing their identity so `errors.Is` continues to work.
- Keep `analyze` as a temporary temporal-analysis client, not an installation mode, database scope, or permanent manager-specific framework.
- Do not call Google Drive, Workspace Directory, Bedrock, Anthropic, or OpenAI.
- Never print, copy, or commit secrets or private document contents.

```go
package cli

type CommandName string

const (
	CommandServe     CommandName = "serve"
	CommandAuth      CommandName = "auth"
	CommandDoctor    CommandName = "doctor"
	CommandSync      CommandName = "sync"
	CommandEntities  CommandName = "entities"
	CommandReview    CommandName = "review"
	CommandAnalyze   CommandName = "analyze"
	CommandDBMigrate CommandName = "db-migrate"
	CommandDBStatus  CommandName = "db-status"
	CommandDBReset   CommandName = "db-reset"
)

type Action string

const (
	ActionAuthGoogle          Action = "google"
	ActionAuthGoogleDirectory Action = "google-directory"
	ActionList                Action = "list"
	ActionShow                Action = "show"
	ActionAccept              Action = "accept"
	ActionAcceptDirectory     Action = "accept-directory"
	ActionReject              Action = "reject"
	ActionCreate              Action = "create"
	ActionCorrect             Action = "correct"
)

type Invocation struct {
	Command         CommandName
	Action          Action
	Arguments       []string
	CreatePerson    *CreatePersonInput
	AcceptDirectory *AcceptDirectoryInput
}

type Command interface {
	Run(context.Context, Invocation) error
}

type CommandFunc func(context.Context, Invocation) error

type Runner struct {
	Execute CommandFunc
	Input   io.Reader
	Output  io.Writer
	Error   io.Writer
}

func (r Runner) Run(context.Context, []string) error
```

Rewrite `internal/app/execute.go` so it creates:

```go
runner := cli.Runner{
	Input:  nil,
	Output: stdout,
	Error:  stderr,
	Execute: func(ctx context.Context, invocation cli.Invocation) error {
		command := config.Command(invocation.Command)
		if err := settings.Validate(command); err != nil {
			return err
		}
		if command == config.CommandServe {
			return runtime.Serve(ctx, settings)
		}
		if commandProvider == nil {
			return fmt.Errorf("%s command is not configured", command)
		}
		commands, err := commandProvider.Commands(ctx, settings, stdout, stderr)
		if err != nil {
			return err
		}
		selected, ok := commands[string(command)]
		if !ok || selected == nil {
			return fmt.Errorf("%s command is not configured", command)
		}
		return selected.Run(ctx, invocation)
	},
}
return runner.Run(ctx, args)
```
